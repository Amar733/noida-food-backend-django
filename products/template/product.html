🍽️ Product Management Dashboard

Manage Chicken, Dry Fruits & Sweets Products

⚙️ API Configuration

🔐 Admin Login (Required for Create/Update/Delete)

Note: Only admin users can create, update, or delete products. Regular users can only view products.

GET Get All Chicken Items

Endpoint: /products/chicken/data
✓ Public Access - No authentication required

POST Create Single Chicken Item

Endpoint: /products/chicken/items
🔒 Admin Only - Authentication required

💡 Tip: ID will be auto-generated. You don't need to provide it.

POST Create Multiple Chicken Items (Bulk)

Endpoint: /products/chicken/data
🔒 Admin Only - Authentication required

PUT Update Chicken Item

Endpoint: /products/chicken/items/{item_name}
🔒 Admin Only - Authentication required

DELETE Delete Chicken Item

Endpoint: /products/chicken/items/{item_name}
🔒 Admin Only - Authentication required
